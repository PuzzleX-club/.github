# Contributing to PuzzleX

Thank you for your interest in contributing to PuzzleX.

## Where to Start

- Open an issue before large changes if you want to discuss direction first.
- Keep pull requests focused and reviewable.
- Prefer small, incremental changes over broad refactors.
- Update relevant documentation when behavior, configuration, or public interfaces change.

## Contribution Expectations

- Public repositories are release surfaces for the PuzzleX stack.
- We prioritize clarity, reproducibility, and public-facing maintainability.
- Security-sensitive findings should not be disclosed in public issues.

## Pull Requests

When opening a pull request:

- explain the problem being solved
- describe the scope of the change
- mention any tests or verification you ran
- keep unrelated cleanup out of the same PR

## Licensing and Contribution Terms

By submitting a contribution, you agree that your contribution may be included in PuzzleX open-source repositories under the repository's applicable license terms, subject to the contributor terms described in [CLA.md](CLA.md).

If you are contributing on behalf of an employer or another organization, make sure you have the right to submit that contribution under those terms.
